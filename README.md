# NFSMW2012 高清特效 (HD Effects)

## 使用方法
1. 下载并解压 [NFSMW2012HDEffects_Chinese.zip](https://github.com/Tikimson/NFSMW2012HDEffects_Chinese/releases)，或者使用未汉化的原版 [NFSMW2012HDEffects.zip](https://github.com/AeroWidescreen/NFSMW2012HDEffects/releases)。
2. 将“scripts”文件夹和“dinput8.dll”文件移动到游戏的安装目录中。
3. 在“NFSMW2012HDEffects.ini”文件中进行设置。
4. 开始游戏。

## 功能特性
- VehicleReflectionRes : 控制车辆反射的分辨率。
- WaterReflectionRes : 控制水面反射的分辨率。
- ShadowRes : 控制场景阴影的分辨率。
- HeadlightShadowRes : 控制车头灯投射阴影的分辨率。
- ReflectionShadowRes : 控制反射效果中阴影的分辨率。
- WorldDistance : 控制整个世界的视距。
- WaterReflectionDistance : 控制水面反射的视距。
- VehicleReflectionDistance : 控制车辆反射的视距。
- EnableHiddenCameras : 启用未使用的摄像机模式。
- TimeCycleSpeed : 决定世界昼夜交替速度的倍率。
- WreckResistance : 决定车辆耐用度的倍率。在线多人模式下无效。
- CinematicMode : 启用一项隐藏设置，可提升细节水平、分辨率及各类特效的质量。
- AutoRefreshGraphics : 解决草地、灌木和树木在更改分辨率之前无法渲染的问题。
- HighShadowRefreshRate : 使阴影实时更新，而不是每隔几秒钟更新一次。
- MotionBlurStrength : 控制动态模糊效果的强度并提高一致性。
- SetReflectionShadow : 允许用户在不影响其他阴影的情况下启用或禁用反射阴影。
- SetDOF : 允许用户在不影响动态模糊的情况下启用或禁用景深效果。
- ToggleHUD : 决定游戏启动时是否启用HUD（平视显示器）。
- ToggleHUDhotkey : 控制游戏过程中切换HUD显示的设置。
- ToggleScreenDirt : 决定启动时是否启用屏幕污渍（Screen Dirt）效果。
- ToggleScreenDirthotkey : 控制游戏过程中切换屏幕污渍效果（Screen Dirt）的设置。
- ToggleTimeOfDayhotkey : 允许用户在午夜、黎明、日出、正午、日落和黄昏之间循环切换。

## 常见问题 (FAQ)
问：此模组兼容哪个版本的游戏？  
答：已在官方 Steam 和 Origin 发布的 1.5 版本上进行过测试。

问：系统配置要求是什么？  
答：对于 1080p 分辨率，使用我提供的设置时，GTX 1060 或 RX 480 显卡应该就足够了。若要使用更高分辨率，则需要性能更强的硬件。

问：我的电脑配置不高，还能使用这个模组吗？  
答：所有设置均可在 INI 文件中进行调整。如果你的电脑原本就能运行这款游戏，那么在使用该模组后，你基本上能获得同样的游玩体验，同时还能享受到模组带来的画质提升。

问：游戏偶尔会崩溃！  
答：尝试禁用 CinematicMode（电影级模式）和 ViewDistance（视距）功能。遗憾的是，受限于显存容量，在某些分辨率下开启这些设置可能会导致运行不稳定。

问：CinematicMode 是什么？  
答：这是一个隐藏设置，能将画质提升至超越原版游戏极限的水平。根据其表现来看，我推测该功能最初是用于制作预告片和截图的。

问：开启 CinematicMode 后可以控制镜头吗？  
答：不能，它仅用于提升画质，没有其他功能。

问：为什么远处的反射效果看起来仍然很模糊？  
答：这是由 Mipmapping（多级渐进纹理）和材质特性引起的。在显卡控制面板中开启 16x 各向异性过滤（Anisotropic Filtering）可以改善画质，不过目前我仅在 NVIDIA 显卡上验证过这一方法。

问：为什么 WreckResistance（抗撞击/耐损）功能在多人联机模式下不起作用？  
答：我不支持任何形式的多人联机作弊行为。加入此功能纯粹是为了提升单人模式的游戏体验。
